# FreeNovel 小白使用说明（源码包）

已于 `2026-04-09` 归档。本文描述的是发布期源码包分发流程，仅为追溯保留，不再代表当前仓库的现行说明。

## 这份说明适合谁
如果你只是想在自己的 Windows 电脑上跑一个能看书的 FreeNovel，本说明就是给你用的。

你不需要先研究代码，也不要一上来就导入旧的超大 SQL。

正确顺序是：
1. 先检查环境
2. 先安装轻量验证包
3. 启动后端
4. 确认网站能打开、能登录、能看演示书
5. 再安装正式阅读包

## 你需要提前准备
- Java 21 或更高版本
- Node.js 20.x LTS
- MariaDB 11 或更高版本

当前源码包已经自带后端预构建文件：
- `release\backend\free-novel.jar`

所以这条小白安装路径不需要 Maven，也不需要单独启动一个前端进程。

## 推荐安装位置
为了尽量少踩路径问题，建议这样放：

- 源码包解压到：`D:\FreeNovel`
- 轻量验证 SQL 放到：`D:\FreeNovel\sql\lite\`
- 正式阅读 SQL 放到：`D:\FreeNovel\sql\reader-full\`

不建议解压到：
- 桌面
- 下载目录太深的子目录
- 含中文用户名的超长路径

如果你一定要放到别的位置，也尽量保证路径短一点。

## MariaDB 安装时怎么选
安装 MariaDB 时，尽量按下面这组来：

- 端口：`3306`
- root 用户密码：`novel_root_password`
- 服务启动方式：开机自动启动

这样你后面基本不用自己改脚本。

如果你安装 MariaDB 时用了别的端口或别的 root 密码，这套小白脚本就不会直接匹配，你需要自己改脚本参数，或者找维护者帮你改。

默认本地地址：
- 后端：`http://localhost:8081`
- 数据库：`127.0.0.1:3306`

默认脚本使用的数据库账号：
- 用户名：`root`
- 密码：`novel_root_password`

如果你的数据库账号密码不是这组，需要自己改脚本里的参数，或者后续再让维护者帮你调整。

## 你会看到的 5 个脚本
源码包根目录现在有这几个中文入口：

- `01-检查运行环境.cmd`
- `02-安装轻量验证包.cmd`
- `03-启动后端.cmd`
- `04-启动前端.cmd`
- `05-安装正式阅读包.cmd`

建议严格按顺序使用。
普通用户的最短路径是：
- `01-检查运行环境.cmd`
- `02-安装轻量验证包.cmd`
- `03-启动后端.cmd`
- 浏览器打开 `http://localhost:8081`

`04-启动前端.cmd` 现在只保留给源码调试，不属于普通用户必需步骤。

## 第一步：检查运行环境
双击：
- `01-检查运行环境.cmd`

正常情况下，它会检查：
- Java
- Node.js
- npm
- MariaDB 客户端
- 后端 jar 文件
- 数据库 `3306` 端口是否能连通
- `8080` 和 `8081` 是否已经被别的程序占用

如果窗口最后显示：
- `Environment check passed.`

说明你的基础环境大体没问题。

如果它报错了，不要继续后面的步骤。先把报错窗口截图保存。

## 第二步：安装轻量验证包
双击：
- `02-安装轻量验证包.cmd`

这个步骤会安装一个很小的验证库：
- 只用于确认部署是否正确
- 带一个演示账号
- 带 3 本演示书

它默认安装到数据库：
- `novel_lite`

安装前请确认这些文件已经放在源码目录里：
- `sql\lite\schema.sql`
- `sql\lite\seed-system-lite.sql`
- `sql\lite\seed-reader-demo.sql`
- `sql\lite\package-manifest.json`
- `sql\lite\README.md`

### 演示账号
- 邮箱：`demo_reader@lite.local`
- 密码：`ReaderPass1`

## 第三步：启动后端
双击：
- `03-启动后端.cmd`

这个脚本会优先尝试连接：
1. `novel_reader_full`
2. 如果没有正式阅读库，再回退到 `novel_lite`

所以你刚装完轻量验证包时，直接双击它就行，不需要自己改数据库名。

看到 Spring Boot 正常启动，并持续输出日志即可，不要关掉这个窗口。

说明：
- 这个启动脚本现在直接使用源码包里的：
  - `release\backend\free-novel.jar`
- 不再要求你另外安装 Maven

## 第四步：打开网站
保持 `03-启动后端.cmd` 的窗口不要关。

然后浏览器打开：
- [http://localhost:8081](http://localhost:8081)

说明：
- 当前后端 jar 已经内嵌前端页面
- 普通使用时不再需要单独启动前端
- `04-启动前端.cmd` 只给源码调试备用

## 第五步：确认轻量验证包能用
先用演示账号登录：
- 邮箱：`demo_reader@lite.local`
- 密码：`ReaderPass1`

确认这几件事：
- 网站能打开
- 能登录
- 能看到演示书
- 能点开目录
- 能打开章节正文

只要这几步都正常，说明你的环境和项目启动链路基本没问题。

## 第六步：安装正式阅读包
轻量验证通过后，再双击：
- `05-安装正式阅读包.cmd`

安装前请确认这些文件已经放在源码目录里：
- `sql\reader-full\schema.sql`
- `sql\reader-full\seed-system.sql`
- `sql\reader-full\reader-content-meta.sql`
- `sql\reader-full\reader-chapter-image-links.sql`
- `sql\reader-full\chapter-parts-manifest.json`
- `sql\reader-full\reader-full-package-manifest.json`
- `sql\reader-full\chapter-part-0001.sql` 到 `chapter-part-0061.sql`

它会把正式阅读内容导入到：
- `novel_reader_full`

这个过程比轻量验证包慢很多，但已经不是以前那种一整坨超大 SQL 的导法了。现在正文已经按分卷拆开，并且支持续跑。

如果中途断了，再次双击这个脚本，会继续用已有进度往下导。

安装完成后，重新使用：
- `03-启动后端.cmd`

它会优先切到 `novel_reader_full`。

## 这两个数据库分别是干什么的
- `novel_lite`
  - 用来验证部署是否正确
  - 很小，适合先试运行

- `novel_reader_full`
  - 用来正式看书
  - 内容更多

## 不要再用旧的大 SQL 安装路径
如果你是小白用户，请不要直接导这些旧文件：
- `sql/main.sql`
- `sql/expand.sql`

这些属于历史维护路径，不再是推荐的普通用户安装方式。

## 常见问题

### 1. 环境检查一开始就失败
先不要继续。

通常是这几种原因：
- 没装 Java
- 没装 Node.js
- MariaDB 没启动
- 源码包里缺少 `release\backend\free-novel.jar`
- `3306` 端口连不上

直接把报错窗口截图发给维护者最省时间。

### 1.1 MariaDB 已经装好了，但密码不是默认值
这套小白脚本默认使用：
- 用户名：`root`
- 密码：`novel_root_password`

如果你自己的 MariaDB 不是这组配置，最简单的方法是：
- 新装一套按默认值来

或者：
- 让维护者帮你改脚本参数后再运行

### 2. 前端能开，但页面没数据
一般是后端没启动成功，或者后端连错数据库了。

先确认：
- `03-启动后端.cmd` 那个窗口有没有报错
- 后端窗口里当前连的是 `novel_lite` 还是 `novel_reader_full`
- 浏览器访问的是不是 `http://localhost:8081`

### 3. 安装正式阅读包中途断掉了
直接重新双击：
- `05-安装正式阅读包.cmd`

当前正式阅读包支持断点续跑，不需要从头删库重来。

### 4. 我只想试试能不能跑
那只用做到这一步：
- `01-检查运行环境.cmd`
- `02-安装轻量验证包.cmd`
- `03-启动后端.cmd`
- 浏览器打开 `http://localhost:8081`

不用先装正式阅读包。
